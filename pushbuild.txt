First Source2Mod release: the 13 fixes of GameFixes_mm ported onto the core's hooks, config (game_fixes.json) and gamedata, plus cstv_bot_quota (off by default); IGameFixes002 adds ServerListPlayersHide / Show. Built against Source2Mod plugin API 7 (needs the matching Source2Mod release).
Rebuilt for Source2Mod plugin API 8: per-plugin interface instances, no plugin ids in calls, modules from g_pSource2ModModules. demo_record is described in gamedata and found with Find().
demo_record holds back only a kick of the GOTV client (NETWORK_DISCONNECT_KICKED), and only while a player is on the server: a shutdown, HLTVSTOP and a kick on an empty server go through, so the engine's repeated kicks no longer loop and the shutdown is not held back; only the first blocked kick per map is logged. cstv_bot_quota is on by default: the engine's bot quota runs on every server, also with bot_quota 0, and takes the GOTV client for a bot.
